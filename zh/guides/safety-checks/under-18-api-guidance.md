# Under 18 API Guidance

> 青少年在线上和线下都有独特的需求，因此开发者在使用我们的 API 为未成年人（18 岁以下）提供服务时，应实施额外的安全措施。

青少年在线上和线下都有独特的需求，因此开发者在使用我们的 API 为未成年人（18 岁以下）提供服务时，应实施额外的安全措施。这些措施是对我们的[使用政策](https://openai.com/policies/usage-policies/)和[条款与条件](https://openai.com/policies/services-agreement/)中要求的补充。

**监管标准**

为未成年人提供服务的组织必须遵守所有适用的儿童保护、安全和隐私法律，包括《儿童在线隐私保护法》（COPPA）。在未首先在我们的 API 中实施零数据保留的情况下，您不应使用 OpenAI 服务处理 13 岁以下儿童或适用数字同意年龄以下儿童的任何个人数据。您全权负责确保您和您的用户在遵守适用法律的前提下使用 OpenAI 服务。

**安全标准**

为未成年人提供服务的组织必须采取合理措施，确保通过 API 向未成年人提供的内容是安全且适龄的，符合我们使用政策中"保护未成年人安全"的要求。这可能包括但不限于：

1.  向未成年人提供关于 AI 工具及如何负责任地使用它们的适龄披露信息。
2.  实施适龄的内容过滤器，以处理潜在的敏感内容。
3.  实施合理的监控和报告机制，包括针对高风险交互的升级路径。
4.  在您的使用场景需要或适当的情况下，使用年龄验证系统以确保只有目标用户可以访问产品。

**最佳实践**

为未成年人提供服务的组织在与我们的 API 交互时应遵循以下最佳实践：

*   在处理未成年人的数据和交互时应格外谨慎，并在识别到对年轻用户的风险时采取适当行动。
*   利用可用的安全工具，并遵循 OpenAI 可能提供的技术安全措施，这些措施旨在为特定用户群体（包括未成年人）定制产品体验。
*   使用 OpenAI 最新的旗舰模型，这些模型包含最新的安全保护措施，尤其是在为未成年人构建体验时。

OpenAI 保留对组织进行合规审计的权利。未能证明合规的客户可能会收到警告，在反复或严重不合规的情况下，可能会被暂停或终止 API 访问权限。
